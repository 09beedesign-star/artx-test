## ProfilePage 上传流程优化完成

**问题：** 用户点击 ProfilePage「我的作品」标签页的上传按钮时，会在 ProfilePage 本地打开上传对话框，导致需要点两次上传才能在社区完成上传。

**解决方案：** 
1. ProfilePage 移除本地 UploadDialog 和 uploadDialogOpen 状态
2. 添加 `goToUploadInCommunity()` 函数，导航到 `/community?upload=true`
3. 「我的作品」标签页右上角添加「上传作品」按钮，点击调用导航函数
4. 空状态「还没有上传过作品」的按钮也改为导航到社区
5. CommunityPage 检查 URL 查询参数 `?upload=true`，自动打开上传对话框
6. 上传对话框关闭时自动刷新帖子列表

**修改文件：**
- `client/src/pages/ProfilePage.tsx` - 移除本地上传逻辑，添加导航函数
- `client/src/pages/CommunityPage.tsx` - 支持自动打开上传对话框，关闭时刷新列表
