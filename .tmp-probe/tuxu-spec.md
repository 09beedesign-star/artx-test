# 图叙 AI 站点 UI 规格提取（www.tuxuai.com）

## 一、配色系统（从 CSS 变量与计算样式提取）

### 浅色主题 (light)
- **背景**: `rgb(255,255,255)` / `#ffffff`
- **文字主**: `rgb(38,38,39)` / `#262627`
- **文字次**: `rgb(119,116,114)` / `#777472`
- **导航 hover**: `rgb(23,23,23)` / `#171717`
- **边框**: `rgb(230,227,223)` / `#e6e3df`
- **次要按钮背景**: `rgb(245,246,248)` / `#f5f6f8`
- **卡片背景**: `rgb(255,255,255)` 略带透明 `rgba(255,255,255,0.94)`
- **输入框 hover**: `rgb(245,246,248)`
- **阴影**: `rgba(48,37,25,0.03) 0px 6px 24px 0px`

### 深色主题 (dark)
- **背景**: `rgb(28,28,28)` / `#1c1c1c`
- **文字主**: `rgb(195,194,183)` / `#c3c2b7`
- **文字次**: `rgb(119,116,114)` / `#777472`（同 light）
- **次要按钮背景**: `rgb(46,50,56)` / `#2e3238`
- **导航 hover**: `rgb(23,23,23)` / `#171717`（同 light）

### 品牌色（主题无关）
- **主按钮**: `rgb(21,21,21)` → `rgb(51,51,51)` (hover)
- **黑色文字**: `rgb(23,23,23)` / `#171717`
- **白色文字**: `rgb(255,255,255)`

## 二、圆角系统
- **大圆角（pill 按钮）**: `999px`
- **卡片/输入框**: `24px` (promptbox) / `16px` (小按钮) / `18px` (选择器)
- **次要按钮**: `12px`

## 三、按钮规格

### 主按钮（注册/设计模板）
- **尺寸**: `h:48px` (导航) / `h:52px` (hero CTA)
- **背景**: `rgb(22,22,22)` → `rgb(51,51,51)` (hover)
- **文字**: `rgb(255,255,255)`
- **圆角**: `999px`
- **padding**: `0px 20px` / `0px 28px`
- **字重**: `500`
- **transition**: `background 0.2s`

### 次要按钮（图片生成、生成参数）
- **尺寸**: `h:32px`
- **背景**: light `rgb(255,255,255)` + border `rgb(230,227,223)`, dark 同但 hover → `rgb(46,50,56)`
- **文字**: `rgb(38,38,39)`
- **圆角**: `16px` / `18px`
- **padding**: `0px 10px`

### 文字按钮（导航链接）
- **背景**: `transparent`
- **文字**: `rgb(119,116,114)` → `rgb(23,23,23)` (hover) / `rgb(34,34,34)` (登录hover)
- **transition**: `all`

### 圆形图标按钮
- **尺寸**: `32x32` / `36x36` / `40x40` / `45x45`
- **背景**: light `rgb(245,246,248)`, dark `rgb(46,50,56)`
- **圆角**: `50%`

## 四、输入框（提示词）
- **容器背景**: `rgb(255,255,255)`（light/dark 通用，白色卡片）
- **圆角**: `24px`
- **阴影**: `rgba(48,37,25,0.03) 0px 6px 24px 0px`
- **padding**: `8px`（外层容器）
- **textarea**:
  - 文字: `rgb(38,38,39)`
  - 字体: `14px/22px`
  - placeholder: `"描述你想创作的内容…"`
- **focus**: 无 border 变化，保持阴影

## 五、字体栈
```
Inter, -apple-system, "system-ui", "Segoe UI", "PingFang SC"
```
- 主力西文: `Inter`（被加载，非 system-ui）
- 中文: `PingFang SC`

## 六、间距与布局
- **导航高度**: 约 `80px`
- **内容区 padding**: 约 `20px` (手机) → `clamp(16px, 3vw, 40px)` (桌面)
- **按钮间距**: `gap: 12px` / `gap: 20px`

## 七、与现有 ArtX 的差异（需要改动的点）

| 维度 | ArtX 现状 | 图叙 AI 目标 |
|------|-----------|--------------|
| **主按钮背景** | `oklch(0.58 0.22 290)` 紫色 | `rgb(22,22,22)` 黑色 |
| **主按钮 hover** | `primary/90` 紫色变暗 | `rgb(51,51,51)` 深灰 |
| **圆角** | `6px` / `--radius-md-design` | `999px` (pill) / `24px` (卡片) / `16-18px` (次要) |
| **次要按钮背景** | light `oklch(0.92 0.003 240)` 浅蓝灰 | light `rgb(245,246,248)` 浅灰 |
| **文字主** | light `oklch(0.15 0.004 240)` | light `rgb(38,38,39)` 更接近黑 |
| **文字次** | light `oklch(0.45 0.006 240)` | light `rgb(119,116,114)` 暖灰 |
| **边框** | light `oklch(0.88 0.003 240)` | light `rgb(230,227,223)` 米白 |
| **阴影** | Apple 风格多层 `0 2px 8px...` | 单层柔和 `0px 6px 24px rgba(48,37,25,0.03)` |
| **字体** | `Inter` 未加载，fallback system-ui | `Inter` 真实加载（观察到 `Inter` 在 computed font-family） |

## 八、实施策略

### 第一阶段：颜色 token 替换（`client/src/index.css`）
1. **主按钮色**: `--primary` 从紫改为黑 `#161616`，hover `#333333`
2. **次要按钮背景**: light `--secondary` 改为 `#f5f6f8`
3. **文字主**: light `--foreground` 改为 `#262627`
4. **文字次**: light `--muted-foreground` 改为 `#777472`
5. **边框**: light `--border` 改为 `#e6e3df`

### 第二阶段：圆角全局替换
1. `:root` 里 `--radius` 改为 `16px`（卡片基础）
2. `--radius-pill` 改为 `999px`
3. 主按钮组件加 `rounded-full` (999px)
4. 输入框容器改为 `24px`

### 第三阶段：组件样式迁移
1. **Button**: `variant="default"` 的 `bg-primary` 已自动继承新色；hover 逻辑改为 `hover:bg-[#333]`
2. **AppShell 导航**: 内联 `isDark ? ... : ...` 的颜色改为新规格（`textPrimary` / `activeBg` 等）
3. **首页提示词输入框**: 白色卡片 + 24px 圆角 + 柔和阴影
4. **次要按钮**: 改为 light `#f5f6f8` + border `#e6e3df`

### 第四阶段：验证与截图对比
1. 本地 3000 跑起来，截图 light/dark 两主题的首页、电商画布、充值页
2. 与参考站对比：主按钮颜色、圆角、文字色、hover 态
3. 检查 hover 过渡是否柔和（`transition: all` / `background 0.2s`）

## 九、保留的设计元素（不改）
- **对话框提示词输入框的交互逻辑**: 保留现有 focus/blur/声音输入等功能
- **整体布局结构**: 不动 grid/flex 布局，只改颜色、圆角、阴影
- **图片生成流程**: 保留模型选择、参数面板等业务逻辑
- **电商画布**: 保留画布交互，只改 UI 组件外观
